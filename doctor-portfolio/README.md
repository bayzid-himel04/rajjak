# Dr. Md. Khairul Islam — Orthopedic Surgeon Portfolio

A modern, responsive portfolio web application built with **Vite.js**, **React 19**, **Tailwind CSS v4**, and **Framer Motion**.

## Tech Stack

- **Framework**: [Vite](https://vite.dev/) + React 19 + TypeScript
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Fonts**: Inter & Playfair Display (Google Fonts)

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the development server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for production

```bash
npm run build
```

### 4. Preview production build

```bash
npm run preview
```
